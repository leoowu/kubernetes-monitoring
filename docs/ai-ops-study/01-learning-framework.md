# AI-Ops / 工程学习框架

> 版本：v0.2 · 日期：2026-08-09（文档标注）· 画像：资深运维 + 多模型重度用户

目标：支撑 AI 原生组织、知识库、流程与平台的核心能力；深入机制（Transformer / DL）；覆盖私有/国内模型部署。

---

## 1. 四轴模型（v0.2）

| 轴 | 名称 | 说明 |
|----|------|------|
| A | 应用工程 | 主干对齐「AI 技术栈六层」 |
| B | 模型机制 | Token → 训练/推理结构 → Transformer/LLM |
| C | 平台运维 | 推理平台、SLO、成本、沙箱、可观测 |
| D | 组织与体系 | v0.2 新增：角色、审批、SOP、Agent harness |

深度默认：A/C/D → L2–L3；B → L2（关键 Transformer 路径可 L3）；避免研究级 L4。

---

## 2. 七阶段主路径（相对 v0.1 的调整）

| Stage | 主题 | v0.2 调整要点 |
|-------|------|----------------|
| 0 | 坐标系 | 北极星定为「AI 组织/平台」；OSI + 六层 + 四轴合一图 |
| 1 | 物理与接口 | 增加 Claude/Codex/Kimi/DeepSeek 多模型对照实验 |
| 2 | 外部能力 | RAG ↔ 组织知识库；MCP ↔ 平台工具总线 |
| 3 | Agent + Harness | 角色、审批门、工作流闭环（对齐轴 D） |
| 4 | DL 基础 | 机制入门（保持） |
| 5 | Transformer/LLM | 私有化视角：结构、上下文、许可 |
| 6 | 推理平台 | 改为「更早启动的并行轨」的汇合终点 |

---

## 3. 并行侧轨（v0.2 新增）

### 侧轨 P · Private Deploy

- 覆盖：Ollama、vLLM、OpenAI-compatible 网关
- **启动点**：Stage 1 末即可开实验，不等到 Stage 6

### 侧轨 O · Org Spec

- 用 SDD 定义「虚拟小团队」：角色、知识边界、人工门禁
- **可执行化**：从 Stage 3 起落地到 Agent/Harness
