## 本轮学习结论（机制层）

1. 北极星是 **AI 组织/平台**，不是 prompt 收集。
2. Token / 无状态 API / 幻觉类别 是后续平台 SLO 与门禁的物理基础。
3. 多模型对照与私有化必须前移；组织规格必须独立成轴。
4. Stage 2：模型只做窗口内推理；**RAG=受权限约束的组织记忆**，**MCP/工具=受沙箱与审计约束的行动总线**。
5. Stage 3：**Agent 办事，Harness 管角色/状态机/审批/审计**；只读诊断可自动，写变更必须过门。
6. Stage 4：运维主场是 **推理**（算力/显存/KV cache/精度/并发），不是自训基座。
