## 4.1 训练 vs 推理：你站在哪一边

### 一句话

| | 训练 Training | 推理 Inference |
|--|----------------|----------------|
| 目的 | **改**模型权重，让它变「会」 | **用**已固定的权重生成输出 |
| 过程 | 前向 → 算损失 → 反向传梯度 → 优化器更新参数 → 反复 | 前向 → 采样 token → 循环（权重不动） |
| 成本形态 | 长周期、大数据、极吃显存 | 按请求持续跑，吃算力/带宽/状态缓存/并发 |

### 为什么先分清

「分词 → 前向 → 采样」描述的是 **推理**。  
本 Stage 默认站在推理侧谈容量与机制；训练只需知其存在且更重，避免概念串台。

### 本步只记

**训练改权重；推理用权重。基础系统学习的主线先吃透推理。**

## 4.2 张量、权重、层：最小对象

### 张量（Tensor）

深度学习里的基本数据形态：多维数组。

| 名字 | 形状直觉 | 例子 |
|------|----------|------|
| 标量 | 单个数 | 一个 loss 值 |
| 向量 | 一维 | 一个 token 的向量表示 |
| 矩阵 | 二维 | 一层的权重表 |
| 高维张量 | 三维及以上 | 一批数据 × 长度 × 特征 |

在加速器（GPU 等）上，计算几乎都是对张量做批量运算。

### 权重 / 参数（Weights / Parameters）

网络里 **可学习、训练后固定下来供推理使用** 的那些数。  
说模型「有 7B / 70B 参数」，主要指这些数的规模——决定了权重大小、显存占用的数量级。

### 层（Layer）

一种约定好的变换：**输入张量 → 输出张量**。  
例如：线性层（矩阵乘 + 偏置）、归一化、激活、注意力块等。

### 网络 / 模型

层按结构堆叠。数据从输入侧一层层传到输出侧，就是一次 **前向**。

```text
输入张量
  → Layer 1 → Layer 2 → … → Layer N
  → 输出张量（再接任务头，如词表 logits）
```

### 本步只记

**张量是数据；权重是模型记住的数；层是变换；网络是层的堆叠。**

## 4.3 前向在算什么

### 定义

**前向（Forward / Forward pass）**：输入张量依次通过各层，得到输出张量的一次完整计算。  
推理时几乎只做前向；训练时前向之后还要算损失与反向。

### 接到「分词 → 前向 → 采样」

对因果语言模型（一次生成一个 token）而言：

```text
token ids
  → Embedding：id → 向量（查表，也是一种参数）
  → 一层层 Transformer 块（注意力 + 前馈等）
  → 输出头：得到词表大小的 logits（每个候选 token 一个分数）
  → （采样步骤，严格说已离开「纯前向」）按分数选出下一个 token id
```

要点：

1. **前向的直接产物**是 logits（或等价分数），不是最终「选中的字」。  
2. **采样**根据 logits（可加温度等）选出一个 id；选完后拼回序列，再跑下一轮前向。  
3. 所以生成一段话 = **很多次前向**（大致每个新 token 一轮，实现上可有优化）。

### 和层的关系

第 2 步说「网络是层的堆叠」。  
前向 = 数据沿这座堆栈走一遍，中间产生大量 **激活（activations）**：各层的中间张量。  
权重是「模型记得的」；激活是「这一次输入算出来的临时结果」。

### 本步只记

**前向 = 输入穿过各层得到 logits；生成 = 前向与采样的反复。**
